The Urbz DS

Decompilation of the USA cartridge. The ROM stays on your machine. This page counts names and matched bytes from the repository.

A function counts as named when its symbol is not an automatic func_ name. dsd finds every function it can, which is a wider set than the notes' count of functions that save registers. Matched bytes are code built from C. That number stays at zero until the compiler version is known.
